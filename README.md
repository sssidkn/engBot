# EngBot — занятия английским в Telegram

Бот на Go: отмечаешь день, когда позанималась, считает серию подряд и показывает календарь (занятие / пропуск). Работает в личке и в групповом чате.

## Что умеет

- `/done` — отметить сегодня
- `/undo` — снять отметку за сегодня
- `/streak` — текущая и лучшая серия
- `/calendar` — сетка месяца: нажми любой прошедший день, чтобы отметить занятие или снять; ◀ ▶ листают месяцы; «← Меню» возвращает к главному меню
- `/stats` — сколько дней всего
- `/board` — таблица участников этого чата
- `/remind 09:00` — напоминание в это время (по своему поясу). Можно несколько: `/remind 09:00 21:30`. В группе бот пишет юзернейм, кому напоминание. Если день уже отмечен — не пишет. `/remind` — список, `/remind off` — выключить.
- `/word run` — словарь: все значения с контекстом, примеры EN+RU и уровень A1–C2. Фразы и русские слова тоже. В личке можно просто текстом. Синонимы: `/w`, `/dict`, `/en`. Для полного разбора нужен бесплатный `GROQ_API_KEY`.
- `/timezone Europe/Moscow` — «сегодня» и напоминания считаются по своему поясу (по умолчанию Москва)


Серия не обнуляется до конца дня: если вчера занималась, а сегодня ещё нет — серия жива.

В группе у каждого своя история занятий. В таблицу `/board` попадают те, кто хотя бы раз написал боту в этом чате.

## Создание бота

1. В Telegram открой [@BotFather](https://t.me/BotFather) → `/newbot` → сохрани токен.
2. `/setcommands` и вставь:

```
done - отметить занятие сегодня
undo - снять отметку за сегодня
streak - серия дней подряд
calendar - календарь месяца
stats - статистика
board - таблица чата
word - словарь: перевод и значения
remind - напоминания о занятии
timezone - часовой пояс
help - список команд
```

3. Чтобы добавить в группу: открой чат → «Добавить» → выбери бота.  
   Команды (`/done` и остальные) работают и при включённой приватности. Если хочешь, чтобы бот видел обычные сообщения, в BotFather: `/setprivacy` → Disable.

4. Права администратора не обязательны.

## Запуск

Нужен [Go 1.22+](https://go.dev/dl/).

```bash
copy .env.example .env
```

В `.env` подставь токен:

```
BOT_TOKEN=123456:ABC-your-token
DATABASE_PATH=data/engbot.json
DEFAULT_TZ=Europe/Moscow
GROQ_API_KEY=gsk_your_free_key
```

Словарь с нормальными значениями, контекстом и CEFR использует бесплатный [Groq](https://console.groq.com/keys). Без ключа останется краткая английская статья. Если в `.env` ещё стоит `llama-3.3-70b-versatile`, её можно убрать: на обычном ключе эта модель больше не доступна, бот сам возьмёт `openai/gpt-oss-120b`.

```bash
go run ./cmd/bot
```

Отметки хранятся в JSON-файле `data/engbot.json` (путь можно сменить через `DATABASE_PATH`).

## Bothost (Docker)

В корне репозитория есть `Dockerfile` под [Bothost](https://bothost.ru/docs/custom-dockerfile): бинарник в `/usr/local/bin/engbot` (вне `/app`, чтобы его не перекрыл mount с Git), база и логи в `/app/data`.

1. Залей код на GitHub (`master` / `main`).
2. На Bothost создай бота, укажи репозиторий и ветку.
3. Включи **«Использовать собственный Dockerfile»**.
4. Секреты — только в переменных окружения панели, не в Git:
   - `BOT_TOKEN` (часто подставляется из поля токена)
   - `GROQ_API_KEY` (если нужен подробный `/word`)
   - при необходимости `HTTPS_PROXY` / `HTTP_PROXY`
5. Внутренний порт `8080` (health `GET /` → `ok`). Long polling, webhook не обязателен.

Без `.env` бот стартует: читает env, если лог или база недоступны — пишет в stderr и `/tmp`.
